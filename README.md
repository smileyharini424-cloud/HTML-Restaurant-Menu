# HTML Restaurant Menu

## Explanation

This project creates a simple restaurant menu webpage using HTML. It displays different food categories along with item names, descriptions, and prices.

## Features

* Restaurant heading
* Breakfast section
* Main course section
* Desserts section
* Food descriptions
* Food prices
* Clean table-based menu layout

## Technologies Used

* HTML5

## Program Flow

1. Display the restaurant name.
2. Display the menu categories.
3. Show food items under each category.
4. Display descriptions and prices.
5. Present the complete menu in a structured format.
